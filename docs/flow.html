Reading the cells

R reads, W writes. A qualifier says how much: "once" means scaffolded on first run and never overwritten; "+1 line" means an append; "last 20 active" means the tail of entries without a Superseded by: line; "last 30 lines" is what Ralph injects into Cody. "archive" means the file is moved out after being consumed.

Authority order

issue text › architecture.md › scout-cache.md › decisions.md › development.md. Higher wins; Cody notes the conflict in the PR body, Reven under Observations, Forge as an open question.

Incident store

One global squad-incidents.tsv for all projects. Besides the checkpoint's denial pass, every squad script appends a line when it fails, whichever step called it. Orient only shows a count once an incident recurs.

Update and forget

A decision that reverses another carries Supersedes:; the old one gets Superseded by:. At 60 active entries the superseded ones move to decisions-archive.md, which nothing loads.
